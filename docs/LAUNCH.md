# איך מעלים את SmartPantry לאוויר ומרוויחים ממנה

המדריך הזה מיועד לבעל האפליקציה. לא צריך לדעת לתכנת: הכל נעשה דרך אתרים, בלחיצות.

## איך זה עובד

```
הטלפון של המשתמש  →  השרת שלכם (Vercel)  →  Claude API של Anthropic
      תמונה              בודק מכסה,             מזהה את המצרכים
                         שולח לזיהוי              ומחזיר רשימה
```

- **המשתמשים לא צריכים שום חשבון.** הם פותחים את האתר, מצלמים, וזהו.
- **המפתח של Claude נמצא רק בשרת שלכם.** אף משתמש לא רואה אותו.
- **אתם משלמים ל-Anthropic לפי שימוש** (בכל סריקה), והמשתמשים משלמים לכם על Premium.
- **השרת מגן על הכסף שלכם:** מכסה חינמית לכל מכשיר, מגבלה יומית לכל כתובת IP, ותקרה יומית כוללת.

## הגדרה ראשונה (בערך חצי שעה)

### 1. חשבון Claude API
1. נכנסים ל-[console.anthropic.com](https://console.anthropic.com) ונרשמים.
2. **Billing:** מוסיפים קרדיט, למשל $20 להתחלה.
3. **Limits:** מגדירים **תקרת הוצאה חודשית**. זו ההגנה הכי חשובה: גם אם משהו ישתבש, לא תשלמו יותר מהתקרה.
4. **API Keys:** יוצרים מפתח חדש ומעתיקים אותו. אל תשלחו אותו לאף אחד, גם לא בצ'אט.

### 2. העלאה ל-Vercel
1. הקוד צריך להיות בענף `main` ב-GitHub (או שבוחרים ב-Vercel את הענף של האפליקציה).
2. ב-[vercel.com](https://vercel.com): **Add New → Project**, בוחרים את המאגר `-cv-click`.
3. **Framework Preset:** Other. לא משנים שום דבר אחר. לוחצים **Deploy**.

### 3. משתני סביבה
ב-Vercel: **Settings → Environment Variables**. מוסיפים:

| שם | מה לשים |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח מסעיף 1 |
| `ADMIN_TOKEN` | סיסמה לדף הניהול: לפחות 16 תווים אקראיים. שמרו אותה בצד. |
| `PREMIUM_PRICE_TEXT` | מה שמוצג במסך השדרוג, למשל `₪14.90 לחודש` |
| `CHECKOUT_URL` | הקישור לדף התשלום שלכם (ראו "תשלומים" למטה) |
| `SUPPORT_EMAIL` | אימייל לפניות |

אחרי השמירה: **Deployments → Redeploy**, כדי שהשינויים ייכנסו.

כל שאר ההגדרות (מכסות, מודל) מפורטות בקובץ `.env.example`, ויש להן ברירות מחדל סבירות.

### 4. אחסון למכסות ולקודים
ב-Vercel: **Storage → Create Database → Upstash (Redis)**, מחברים לפרויקט, ועושים Redeploy.
בלי זה המכסות והקודים נמחקים בכל הפעלה מחדש של השרת. הגרסה החינמית של Upstash מספיקה להתחלה.

### 5. בדיקה
1. פותחים את כתובת האתר (משהו כמו `smartpantry.vercel.app`), מצלמים את המקרר שלכם, ובודקים שהזיהוי נכון.
2. פותחים את `/admin.html`, נכנסים עם ה-`ADMIN_TOKEN`. אם יש התראה צהובה או אדומה, היא אומרת בדיוק מה חסר.

## תשלומים

**Stripe כנראה לא זמין לעסקים בישראל**, ולכן האפליקציה לא תלויה בספק תשלום מסוים. היא עובדת עם **קודי הפעלה**:

1. הלקוח לוחץ "לרכישת Premium" ועובר לדף התשלום שלכם (`CHECKOUT_URL`).
2. אחרי התשלום אתם שולחים לו קוד הפעלה. את הקודים יוצרים בדף הניהול: כמה קודים, לכמה ימים, והערה עם שם הלקוח.
3. הלקוח מזין את הקוד באפליקציה, ו-Premium נפתח עד התאריך שבחרתם. אותו קוד עובד על עד שני מכשירים.

אפשרויות לדף תשלום:
- **ספקים ישראליים** (למשל Grow/משולם, PayPlus, CardCom): תומכים בביט ובכרטיסי אשראי ישראליים. צריך עוסק פטור או מורשה.
- **Merchant of Record בינלאומי** (למשל Lemon Squeezy, Paddle): הם מטפלים במע"מ ובחשבוניות בשבילכם. בדקו אצלם שהם מקבלים מוכרים מישראל, כי לא הצלחתי לאמת את זה.

**המלצה להתחלה:** למכור כרטיסיות של חודש, 3 חודשים ושנה, ולא מנוי מתחדש. זה מתאים לקודים, ופשוט ללקוח ולכם.
רבים מדפי התשלום יודעים לשלוח אימייל אוטומטי אחרי רכישה, ואפשר לשים בו את הקוד. כשתבחרו ספק, אפשר להוסיף חיבור אוטומטי מלא: התשלום יוצר קוד ושולח אותו לבד.

## כמה זה עולה (מספרים כנים)

**עלות AI לסריקה** (3 תמונות, הערכה; העלות האמיתית מופיעה בדף הניהול):

| מודל (`CLAUDE_MODEL`) | לסריקה | הערה |
|---|---|---|
| `claude-opus-5-5` (ברירת מחדל) | בערך 7–16 סנט | המדויק ביותר |
| `claude-sonnet-5-5` | בערך 4–8 סנט | |
| `claude-haiku-5-5` | פחות מחצי סנט | הכי זול בהרבה |

יצירת מתכונים עולה בערך 4 סנט ב-Opus.

**דוגמה:** משתמש חינמי שעושה 5 סריקות ו-5 יצירות מתכונים בחודש עולה בערך $0.80 בחודש ב-Opus, ובערך 2 סנט ב-Haiku. ל-1,000 משתמשים חינמיים זה הבדל בין בערך $800 לבערך $20 בחודש.
**לפני ההשקה כדאי לבדוק** את המקרר האמיתי שלכם עם כל מודל (משנים את `CLAUDE_MODEL` ועושים Redeploy), ולבחור את הזול ביותר שעדיין מזהה טוב. אפשר גם להוריד את מספר הסריקות החינמיות (`FREE_SCANS_PER_MONTH`).

**אירוח:**
- **Vercel:** התוכנית החינמית מיועדת לשימוש לא מסחרי. ברגע שגובים כסף צריך Pro ($20 לחודש).
- **Upstash:** חינם בהתחלה.

## להפוך את זה לאפליקציה בטלפון
- **כבר עכשיו:** זו אפליקציית רשת שאפשר להתקין. באייפון: Safari ← שיתוף ← "הוסף למסך הבית". באנדרואיד: Chrome מציע התקנה.
- **חנויות האפליקציות:** אפשר לארוז את האתר כאפליקציה (למשל עם PWABuilder). שימו לב: Apple ו-Google דורשות בדרך כלל את מערכת התשלומים שלהן למנויים דיגיטליים בתוך האפליקציה. זה שלב נפרד, אחרי שהאתר מוכיח את עצמו.

## רשימת בדיקות לפני השקה
- [ ] תקרת הוצאה חודשית מוגדרת ב-console.anthropic.com
- [ ] Upstash מחובר (בדף הניהול לא מופיעה התראה על אחסון)
- [ ] `ADMIN_TOKEN` מוגדר ושמור אצלכם
- [ ] סרקתם את המקרר שלכם כמה פעמים ובחרתם מודל
- [ ] דפי הפרטיות ותנאי השימוש הושלמו ונבדקו על ידי עורך דין
- [ ] `CHECKOUT_URL` ו-`PREMIUM_PRICE_TEXT` מוגדרים, וקניתם קוד בעצמכם מתחילת התהליך ועד הסוף
- [ ] Vercel Pro לפני שמתחילים לגבות כסף
- [ ] (רשות) דומיין משלכם: Vercel → Settings → Domains

## יום־יום
- **מכירה חדשה:** דף הניהול ← "יצירת קודי Premium" ← שולחים את הקוד ללקוח.
- **לקוח החליף טלפון:** אותו קוד עובד על מכשיר שני. אפשר גם לבדוק או לבטל קוד בדף הניהול.
- **מעקב הוצאות:** בדף הניהול יש עלות משוערת לחודש. אם מופיעה שגיאת "נגמר הקרדיט", מוסיפים קרדיט ב-console.anthropic.com.
- **שינוי מכסות או מודל:** משנים משתנה ב-Vercel ועושים Redeploy.
