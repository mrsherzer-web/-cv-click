# GEFEN 2 – THE DEMON RETURNS

משחק ההמשך של "הסנוקר של גפן". שבוע אחרי הלילה ההוא גפן מפסיק לענות לטלפון. אתם חוזרים למתחם הסנוקר הנטוש ומגלים שהשד מעולם לא עזב.

שישה לילות. חדר אבטחה עם 12 מצלמות, ומשימות בגוף ראשון בתוך המתחם. המטרה היא להציל את כולם, לא להרוג אף אחד.

המשחק נמצא כולו בתיקייה `gefen2/`. המשחק הראשון נשאר בשורש המאגר ולא נגעו בו.

## איך משחקים

כל שעה במשחק היא דקה. כל לילה בנוי משלבים, וכל שלב הוא נקודת שמירה. אם נתפסתם חוזרים לתחילת השלב, לא לתחילת הלילה.

## האויבים

כל אחד מתנהג אחרת, לכל אחד יש סימן אזהרה, ולכל אחד יש תגובה שאפשר ללמוד.

| מי | איך הוא מגיע | סימן אזהרה | מה עושים |
|---|---|---|---|
| **גפן** | מהמסדרון הראשי, מול השולחן | צעדים כבדים, עיניים אדומות בחושך | מאירים עליו בפנס עד שהוא נסוג. המסכה לא עובדת עליו |
| **עידו** (מלילה 3) | שקט ומהיר, דרך פירי האוורור | חבטות מתכת מהפיר, עיניים כתומות בפתח | כשהוא בפתח שמים מסכה ומחכים שילך. בהליכה הוא זז רק כשלא מסתכלים עליו |
| **דולב** (מלילה 3) | מקלקל מצלמות וחשמל, ומתקדם בזמן שמתקנים | הפרעות במסך, זמזום חשמלי, עיניים כחולות | מתקנים מהר בטאבלט, מושכים אותו אחורה עם רעש, ואם הוא בדלת מושכים את מתג הניתוק |

המשאבים: חשמל (טאבלט, אור בפירים, הסחות ותיקונים צורכים אותו), סוללת פנס, וכדורי סנוקר לזריקה.
אם גפן תופס אתכם בהליכה יש הזדמנות אחת להשתחרר בלחיצות מהירות.

## הלילות

1. **הוא עדיין כאן**: פתיחה בגוף ראשון, מאבק, בריחה לחדר האבטחה. אין קליטה. תקלת חשמל ויציאה לחדר החשמל.
2. **החברים בדרך**: הקליטה חוזרת, שיחה עם יהלי ומעיין, הפעלת מערכת הכניסה, חילוץ החברים פנימה.
3. **החברים שהשתנו**: עידו ודולב מופיעים במצלמות. קפיצת קושי. המסכה נכנסת למשחק.
4. **משימת החילוץ**: מוציאים את בעל הבקבוק ואת החייכן מהאזורים הנעולים ומלווים אותם לחדר.
5. **החשמל נופל**: תאורת חירום אדומה, נתיכים בכל המתחם, המרתף והכדור השחור.
6. **THE FINAL NIGHT**: מכניסים את הכדורים לפי הסדר לשולחן המקולל, ואז את השחור. סיום, קרדיטים, וסצנה אחרי הקרדיטים.

## הרצה

המשחק הוא אתר סטטי, בלי שלב בנייה.

```bash
python3 -m http.server 8000
# ואז פותחים http://localhost:8000/gefen2/
```

### באייפון

פותחים את הכתובת של המשחק ב-Safari, לוחצים על "שיתוף" ואז "הוסף למסך הבית". המשחק נפתח במסך מלא ועובד גם בלי אינטרנט אחרי הטעינה הראשונה. מומלץ לסובב את הטלפון לרוחב.

### קבצים להפצה

```bash
python3 gefen2/tools/package.py all
```

| קובץ | למה הוא משמש |
|---|---|
| `dist/gefen2.html` | כל המשחק בקובץ אחד. נפתח בלחיצה כפולה, בלי שרת ובלי אינטרנט |
| `dist/gefen2-web.zip` | להעלאה ל-Game Jolt או ל-itch.io כמשחק HTML |
| `gefen2/sw.js` | רשימת הקבצים לשימוש בלי אינטרנט. הפקודה מעדכנת אותה |
| `dist/gefen2-artifact.html` | גוף הדף בלבד, לפרסום כ-Artifact פרטי ב-claude.ai |

הבנייה של הקובץ היחיד צריכה את `esbuild` (משתנה הסביבה `ESBUILD` או התקנה עם `npm i esbuild`).

### קובץ הפעלה ל-Windows

```bash
python3 gefen2/tools/package.py html
cp dist/gefen2.html gefen2/desktop-lite/resources/index.html
cd gefen2/desktop-lite
npm i @neutralinojs/neu
npx neu update
npx neu build --release --embed-resources
```

נוצר `gefen2/desktop-lite/dist/Gefen2/Gefen2-win_x64.exe`, קובץ אחד של כ-5.5MB שכל המשחק בתוכו. הוא משתמש במנוע הדפדפן שמובנה ב-Windows 10 ו-11. הקובץ נבנה אבל לא הופעל על מחשב Windows אמיתי.

## מצב הנכסים

כל הדמויות במשחק בנויות מהתמונות האמיתיות של החברים: הראש האמיתי של כל אחד על גוף מצולם, עם רגליים ונעליים, ולאויבים מראה השד מהמשחק הראשון. הכלי: `python3 gefen2/tools/build_assets.py`.

הנכסים מ-Higgsfield (דמויות מלאות, סרטוני הפחדה וסיפור, מוזיקה ודיבוב) עדיין לא נוצרו. הסיבה, הפרומפטים ושמות הקבצים המדויקים נמצאים ב-[docs/HIGGSFIELD.md](docs/HIGGSFIELD.md). כל קובץ שנכנס למקום שלו מחליף אוטומטית את הגרסה המקומית.

בינתיים הסאונד כולו מיוצר בזמן אמת בדפדפן, והדיבוב משתמש בקול העברי המובנה של המכשיר, עם כתוביות.

## בדיקות

```bash
python3 -m http.server 8123 --bind 127.0.0.1 &

# טייס אוטומטי משחק את כל הלילות מההתחלה עד הסוף, בלי מצב חסין
node gefen2/tools/test_nights.js nights=1,2,3,4,5,6 speed=10 limit=260 deaths

# כל נקודה במפה נגישה בהליכה
node gefen2/tools/test_nav.js

# צילומי מסך מבוימים: כל דמות, הפחדות, תפריט, גודל מסך של טלפון
node gefen2/tools/shots_game.js /tmp/shots

# רגעי הסיפור של כל לילה והסיום, בהרצה מואצת
node gefen2/tools/shots_story.js /tmp/story
```

פרמטרים לפיתוח בכתובת: `?dev`, `?night=3&stage=1`, `?god`, `?bot`, `?speed=10`, `?mute`, `?q=0` עד `?q=2`.
