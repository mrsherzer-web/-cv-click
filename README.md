# חייו של נהוראי פרחי

משחק פעולה עירוני בגוף שלישי, בעולם פתוח קומפקטי: קציר, הדרך דרך גן שמואל, וחדרה עד הים. רץ בדפדפן של הטלפון, בתלת־ממד (Three.js), עם שליטה במגע ועם ממשק בעברית.

**שני פרקים:** בפרק הראשון שבע משימות, מהרגע שנהוראי יוצא מהבית לאסוף את אברהם ועד שכל החבר׳ה חוזרים אליו בסוף. בפרק השני ארבע משימות: הבוקר שאחרי בחדר המבולגן, הדר בן עמי שחזר מניו יורק, ביקור בקיוסק ומרדף. בין לבין העולם פתוח: פעילויות שאפשר לחזור עליהן, מוסך, טלפון, ודולב והדר שבאים כשקוראים להם.

כל הדמויות, העסקים והאירועים במשחק בדיוניים. המפה בהשראת המקומות, בלי טענה לדיוק.

## מה יש במשחק

| | |
| --- | --- |
| **העולם** | קציר על הגבעה (הבית, רחוב הרימון, התצפית, המרכז המסחרי והמכון ליד השער), כביש הגישה למישור, הדרך דרך גן שמואל (בריכות דגים, פרדסי הדרים, שער הקיבוץ, תחנת דלק), וחדרה: שדרה עם חנויות, בלוקים של שיכונים, פארק, אזור תעשייה עם המגרש, מוסך, קיוסק, טיילת וחוף. |
| **הרנו הלבנה** | נהיגה ארקייד: גז, ברקס ורוורס, בלם יד שמחליק, ירידות ועליות, התנגשויות שפוגעות ברכב. במוסך הצומת: תיקון, צבע ושדרוגים. |
| **אגרופים** | אגרוף (בקומבינציה: ג׳אב, קרוס, הוק, ובפרק השני גם אפרקאט), הגנה (להחזיק) והתחמקות. עיגול אדום נסגר לפני כל מכה של יריב, ואחריה הוא פתוח לרגע (עיגול צהוב) למכת נגד. מד בריאות ומד כוח. מכה היא הבזק לבן; יריב שהובס יושב בצד. בלי דם ובלי נשק. |
| **החבר׳ה** | אברהם, יונתי, ארז, מולר, דולב והדר, כל אחד עם דרך דיבור משלו. בטלפון אפשר להתקשר אליהם; דולב והדר באים, הולכים אחרי נהוראי, נכנסים לרכב ועוזרים בקרבות של משימות. |
| **ההתרעה** | מד שעולה כשהכרישים (חבורה בדיונית) רואים את נהוראי איפה שלא צריך, או כשהמכוניות שלהם רודפות אחריו. אין משטרה במשחק. |
| **בעיר** | תנועה קלה של מכוניות, ועוברי אורח שזזים מהדרך. אי אפשר להכות אותם, ואין שום תגמול על פגיעה בהם. |
| **צליל** | מנוע, צמיגים, מכות, תאונות, טלפון וצלילי סיום, כולם נוצרים בקוד. כפתור השתקה ליד הכסף. |
| **שמירה** | הכול נשמר בדפדפן (כסף, משימות, שדרוגים, שיאים). במסך הפתיחה: ״להמשיך״ או ״משחק חדש״; בתפריט ההשהיה: ״להתחיל מחדש״, עם אישור. |

### המשימות

| | איפה מתחילה | מה עושים |
| --- | --- | --- |
| 1. **אוספים את אברהם** | מיד בתחילת המשחק, ליד הבית | לרנו הלבנה בחניה, לבית של אברהם ברחוב הרימון, לעצור בסימון וללחוץ ״התקשר לאברהם״, ולחדר הכושר ליד השער לפגוש את יונתי, ארז ומולר. |
| 2. **החבורה במכון** | הסימון הכחול בחדר הכושר | שש מכות בשק, שלוש חסימות ושלוש התחמקויות מול ארז, ספרינג מול יונתי בזירה, וסיפור על הרמקול שנעלם. |
| 3. **יורדים לחדרה** | הסימון הכחול ליד הרנו (או פשוט להיכנס אליה) | במורד הגבעה ודרך גן שמואל, שיחה מארז, עצירה בתחנת הדלק, ״להמשיך לחדרה״, וחניה בחנייה ליד הקיוסק בשדרות הים. |
| 4. **לא מתקפלים** | הסימון הכחול ליד הקיוסק בשדרה | שיחה עם הדרבנים ליד הקיוסק, למגרש מאחורי המוסכים (ברגל), שני סיבובים, והרמקול חוזר לרנו. |
| 5. **מרימים לדולב** | מתקשרים לדולב מהטלפון (הכפתור למעלה משמאל) | לאסוף את דולב ליד סוכת המציל בחוף, לנסוע איתו לחניון החוף ולצאת מהרכב, ולעזור לבן הדוד שלו מול הכרישים. |
| 6. **המכה הראשונה** | הסימון הכחול ליד המשאית של ניסים בחניון החוף | לחצר של הכרישים באזור התעשייה, להיכנס ברגל, להגיע לגנרטור בלי שהשומר יראה, להעמיס אותו לרנו ולנסוע לניסים. אם השעון נגמר לפני שהגעתם, קודם לאבד את המכוניות שלהם. |
| 7. **חוזרים הביתה** | אברהם מתקשר לבד, כמה שניות אחרי משימה 6 | נסיעה נגד השעון דרך ארבע נקודות (יציאה מחדרה, גן שמואל, מרגלות הגבעה, השער של קציר), חניה בבית, וכל החבר׳ה ביחד. |

### הפרק השני

| | איפה מתחילה | מה עושים |
| --- | --- | --- |
| 1. **בוקר אחרי** | הסימון הכחול בדלת של נהוראי (להיכנס לישון) | מתעוררים בחדר המבולגן, מתקשרים לארז מהטלפון, מסדרים שלוש ערימות, יוצאים, והולכים לבית של הדר ברחוב הרימון. |
| 2. **ניו יורק במכון** | הסימון הכחול ליד הרנו (או להיכנס אליה) | נוסעים עם הדר למכון, החבר׳ה פוגשים אותו, הוא מלמד אפרקאט (ארבע מכות ברצף בשק), וספרינג מולו בזירה. |
| 3. **ביקור בקיוסק** | הסימון הכחול ליד הקיוסק בשדרה | בולדוזר אומר שהיה מזל, ובמגרש מאחורי המוסכים סיבוב של שניים על שניים: נהוראי והדר מול בולדוזר ושפיץ. |
| 4. **מרדף אחרי הכפפות** | מיד אחרי המגרש (או מהסימון בשער המגרש) | בולדוזר לקח את התיק של הדר עם הכפפות מניו יורק: נוסעים אחרי הירוקה עד תחנת הדלק בלי לאבד אותה. |

**איך יודעים לאן ללכת:** בחלונית המטרה למעלה מימין כתוב מספר המשימה ושמה, מה לעשות עכשיו, ומתחת חץ עם המרחק במטרים. ביעד עצמו יש עמוד אור וטבעת על הקרקע, ובמפה הקטנה נקודה. בין משימות החלונית אומרת מה המשימה הבאה ואיפה היא מתחילה, והסימון שלה כחול. פעילויות מסומנות בירוק. בתפריט ההשהיה יש רשימה של כל שבע המשימות: מה הושלם (ואפשר לשחק שוב), מה עכשיו, ומה הבא.

**פעילויות (שוב ושוב, בתשלום כל פעם):** אתגר השק, ספרינג חוזר, משלוחים מהקיוסק, וסיבוב שעון מהמכון לחוף. הן מסומנות בירוק במפה.

## איך משחקים

- הקובץ `dist/play.html` הוא המשחק כולו בקובץ אחד, בלי צורך באינטרנט או בשרת.
- בטלפון: מסובבים לרוחב. נדרש דפדפן עם WebGL2: ‏Chrome עדכני באנדרואיד, או Safari ב־iOS 15 ומעלה.

| פעולה | בטלפון | במחשב |
| --- | --- | --- |
| תנועה | אגודל שמאל על המסך (ג׳ויסטיק) | W A S D או החצים |
| מצלמה | גרירה בצד ימין של המסך | גרירה עם העכבר |
| ריצה | כפתור ״ריצה״ (הפעלה וכיבוי) | Shift |
| פעולה | הכפתור שמופיע ליד דברים שאפשר להפעיל | E |
| נהיגה | אגודל שמאל להיגוי, גז וברקס מימין | W/S לגז וברקס, A/D להיגוי, רווח לבלם יד, F ליציאה |
| אגרוף · הגנה · התחמקות | הכפתורים שמופיעים ליד שק או מול יריב | J · K (להחזיק) · L או רווח |
| טלפון · השתקה · השהיה | הכפתורים למעלה משמאל | Esc להשהיה |

כפתורים מופיעים רק כשיש להם מה לעשות: הדוושות ברכב, האגרופים ליד שק או בקרב, ״לענות״ כשמישהו מתקשר, הנסיעה לחדרה בתפריט רק כשהיא פתוחה.

בתפריט ההשהיה: איכות גרפיקה (נמוכה או בינונית, משפיעה גם על כמות המכוניות והאנשים), משחק חוזר של כל משימה שהושלמה, נסיעה מהירה לחנייה בחדרה, חזרה לבית, החזרת הרכב לכביש, והתחלה מחדש.

## פרסום כדי לשחק מהטלפון

המשחק הוא קבצים סטטיים, אז כל אירוח של אתר סטטי מתאים, למשל GitHub Pages מהמאגר הזה (Settings ← Pages ← Deploy from a branch), ואז הכתובת היא `.../dist/play.html`. אם המאגר ציבורי, גם המשחק יהיה ציבורי.

## פיתוח (במחשב)

```bash
npm install          # מתקין את Three.js ואת esbuild
npm run serve        # שרת מקומי: http://localhost:8080 (הגרסה המודולרית, index.html)
npm run build        # בונה את dist/play.html ואת dist/characters.html (כל אחד קובץ אחד)
npm test             # בדיקות הקבלה של כל השלבים, בדפדפן Chromium עם מגע מדומה
```

הבדיקות מריצות את המשחק עצמו: מגע אמיתי על הכפתורים, נהיגה של טייס אוטומטי בכבישים, ובוט קרב שלוחץ על אותן פעולות כמו הכפתורים כשצריך תזמון מדויק. שניהם קיימים רק לבדיקות.

## גבולות

- הדמויות הן גרסאות בדיוניות. השיחות נכתבו למשחק ולא מתארות את האנשים האמיתיים. אין לייחס להם שום פעילות פלילית או אלימה.
- אין כתובות אמיתיות ואין עסקים אמיתיים. ה״שוד״ במשימה 6 הוא החזרה של גנרטור מחבורה בדיונית, בלי שום שיטה מעשית.
- אין העתקה של מפה, מוזיקה, קוד או ממשק של GTA; כל הנכסים נוצרים בקוד.
- אין תגמול על פגיעה בעוברי אורח, ואי אפשר להכות אותם.
