# 👹 אל תעירו את נועם — קומונת דימונה

משחק אימה בגוף ראשון שמתרחש בדירה של **קומונת דימונה**.
4 לילות. משימות. נועם אמירם ישן בחדר בנים — ואסור להעיר אותו.

## 🪟 גרסת Windows

* **`DontWakeNoam-Setup-<גרסה>.exe`** — מתקין: לוחצים פעמיים, "הבא", "התקן". נוצר קיצור דרך בשולחן העבודה ובתפריט התחל, והמשחק מופיע ב"אפליקציות מותקנות" (להסרה). לא צריך הרשאות מנהל.
* **`DontWakeNoam-Portable-<גרסה>.zip`** — בלי התקנה: מחלצים ומפעילים את `DontWakeNoam.exe`.
* המשחק נפתח במסך מלא. **F11** (או Alt+Enter) מחליף לחלון. ההתקדמות נשמרת אוטומטית.
* בפעם הראשונה Windows עשוי להציג "Windows protected your PC" (כי הקובץ לא חתום דיגיטלית) — לוחצים **More info → Run anyway**.

**בנייה מחדש** (מכל מחשב, גם Linux/Mac, בלי Wine):

```bash
npm install
npm run desktop:win   # → desktop/dist/DontWakeNoam-Setup-*.exe + DontWakeNoam-Portable-*.zip
```

## הלילות

1. **השקט** — נועם ישן. מוצאים את המפתח, פוגשים את אורי, משיגים פנס ומכשיר קשר (ירין עולה בקשר), וגונבים את יומן הקומונה מהחדר שלו.
2. **ההתעוררות** — החשמל נפל. לוקחים את המפתח מהשידה של נועם, מוצאים נתיך, מחזירים חשמל... והטלוויזיה נדלקת בפול ווליום. נועם מתעורר — ומעכשיו הוא ער לתמיד. אורי בורח ונעלם.
3. **הקול בקשר** — נועם מסתובב בדירה. אורי חוזר בקשר. פותרים את הקוד של מחסן הגג ועוקבים אחרי המים.
4. **DIMONA DEMONS** — מסיחים את דעתו של נועם עם פיפא, גונבים לו את המפתח מהכיס, משחררים את כולם ושורפים את המסכה.

**טיפים:** כשנועם ישן — תתכופף ליד החדר שלו ואל תכוון לו פנס לפנים. הפנס עוזר לך לראות, אבל גם עוזר לו לראות אותך. כשהוא ליד המחבוא — תעצור את הנשימה.

כדי לפתוח את כל הלילות בלי לעבור אותם, מוסיפים לכתובת `?all` .

## פיתוח

המשחק כתוב ב־JavaScript עם [three.js](https://threejs.org). כל הצלילים והמוזיקה נוצרים בזמן אמת (Web Audio) — אין קבצי סאונד.

```bash
npm install
npm run build   # בונה את build/game.js
npm run dev     # בנייה אוטומטית בכל שינוי
```

* `src/commune.js` — המפה של הדירה (לפי הסרטונים).
* `src/story.js` — ארבעת הלילות, המשימות והדיאלוגים.
* `src/noam.js` — הבינה המלאכותית של נועם.
* `src/audio.js` — כל הסאונד והמוזיקה.
* `src/assets.js` — התמונות של הדמויות (נוצר מהתמונות והסרטונים).
