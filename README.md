# חייו של נהוראי פרחי

אבטיפוס של משחק פעולה עירוני בגוף שלישי, בעולם פתוח קומפקטי בהשראת קציר. המשחק רץ בדפדפן של הטלפון, בתלת־ממד (Three.js), עם שליטה במגע.

**מצב נוכחי: שלב א (בסיס).** רחוב אחד בקציר, נהוראי, מצלמת גוף שלישי, הליכה וריצה, ומטרה קצרה: להגיע לתצפית בסוף הרחוב. הרכב, החברים, המשימות והקרבות מגיעים בשלבים הבאים (ראו [docs/plan.md](docs/plan.md)).

**חדר הדמויות** (`dist/characters.html`, או הכפתור "חדר הדמויות" במסך הפתיחה): כל שש הדמויות, כל אחת בנפרד או כולן יחד, בעמידה, הליכה או ריצה, עם תקריב לפנים. המראה מבוסס על התמונות ששלחתם (ראו [docs/characters.md](docs/characters.md)).

כל הדמויות והאירועים במשחק בדיוניים.

## איך משחקים

- הקובץ `dist/play.html` הוא המשחק כולו בקובץ אחד, בלי צורך באינטרנט או בשרת.
- בטלפון: פותחים את הקישור למשחק (אחרי פרסום, ראו למטה) ומסובבים את הטלפון לרוחב.
- נדרש דפדפן עם WebGL2: ‏Chrome עדכני באנדרואיד, או Safari ב־iOS 15 ומעלה.

| פעולה | בטלפון | במחשב |
| --- | --- | --- |
| תנועה | אגודל שמאל על המסך (ג׳ויסטיק) | W A S D או החצים |
| מצלמה | גרירה בצד ימין של המסך | גרירה עם העכבר |
| ריצה | כפתור "ריצה" (הפעלה וכיבוי) | Shift |
| פעולה | הכפתור שמופיע ליד דברים שאפשר להפעיל | E |
| השהיה | הכפתור למעלה משמאל | Esc |

בתפריט ההשהיה אפשר לבחור איכות גרפיקה נמוכה או בינונית ולחזור לבית של נהוראי.

## פרסום כדי לשחק מהטלפון

המשחק הוא קבצים סטטיים, אז כל אירוח של אתר סטטי מתאים. האפשרות הפשוטה: GitHub Pages מהמאגר הזה (Settings ← Pages ← Deploy from a branch), ואז הכתובת היא `.../dist/play.html`. אם המאגר ציבורי, גם המשחק יהיה ציבורי.

## פיתוח (במחשב)

```bash
npm install          # מתקין את Three.js ואת esbuild
npm run serve        # שרת מקומי: http://localhost:8080 (הגרסה המודולרית, index.html)
npm run build        # בונה את dist/play.html ואת dist/characters.html (כל אחד קובץ אחד)
npm test             # בדיקות קבלה של שלב א ושל חדר הדמויות בדפדפן Chromium עם מגע מדומה
```

## מבנה הקוד

```
index.html             נקודת הכניסה למשחק (מודולים)
characters.html        חדר הדמויות
src/main.js            אתחול, לולאת המשחק
src/config.js          כל המספרים שאפשר לכוונן
src/world/             קציר: שטח, רחוב, בתים, צמחייה, פריטי רחוב, שמיים, התנגשויות
src/player/            נהוראי: התנועה והשליטה
src/characters/        הדמויות: רשימת המראה (roster.js), בניית גוף וראש, אנימציה, חדר הדמויות
src/camera/            מצלמת גוף שלישי
src/input/             ג׳ויסטיק, גרירת מצלמה, מקלדת
src/ui/                ממשק בעברית (style.css, hud.js)
src/missions/          המטרה של שלב א
src/save/              הגדרות שנשמרות בדפדפן
vendor/three/          Three.js r170 (רישיון MIT)
tools/                 בנייה לקובץ אחד ושרת מקומי
tests/                 בדיקות קבלה
docs/                  תוכנית השלבים ועיצוב הדמויות
archive/life-sim.html  גרסה ראשונה שנזנחה (משחק חיים טקסטואלי)
```
