# עדי ויינשטיין · אתר UGC

אתר תדמית ומחירון לעדי ויינשטיין, יוצר תוכן UGC. האתר בנוי מקבצים סטטיים בלבד (HTML, CSS ו־JS), בלי שלב בנייה ובלי תלויות.
אפשר לפתוח את `index.html` ישירות בדפדפן.

התוכנית העסקית המלאה (איך מוצאים לקוחות, תסריט פנייה ותמחור) נמצאת בקובץ [`PLAN.md`](PLAN.md).

## מה יש באתר
- **פתיח** עם השם, התמונה ומדבקת "החל מ־500 ₪".
- **למה UGC:** ההסבר לבעל העסק.
- **ככה זה נראה:** מוקאפ של טלפון ולמי זה מתאים.
- **התפריט:** מחירון אינטראקטיבי. בוחרים חבילה ותוספות, החשבון מתעדכן, ו"שליחה" פותחת וואטסאפ עם ההזמנה כתובה מראש.
- **איך זה עובד**, **קצת עליי**, **שאלות נפוצות** ו**צרו קשר** (כולל QR לוואטסאפ למי שגולש מהמחשב).
- בטלפון יש פס תחתון קבוע עם כפתור וואטסאפ. כשגוללים למחירון הוא מציג את הסכום של ההזמנה.

## איך מעלים לאוויר (חינם)
**הכי מהיר, Netlify Drop:** נכנסים ל־app.netlify.com/drop וגוררים את כל התיקייה לדפדפן. מקבלים קישור תוך דקה.

**GitHub Pages:** ממזגים את הענף ל־`main`, ואז ב־Settings → Pages בוחרים `main` / root.

**Vercel:** מייבאים את הריפו. אין צורך בשום הגדרה.

אחרי שיש כתובת קבועה, מעדכנים ב־`index.html` את `og:image` לכתובת מלאה (למשל `https://<הדומיין>/assets/img/og.jpg`).
בלי זה, התמונה לא תופיע בתצוגה המקדימה כששולחים את הקישור בוואטסאפ.

## איך משנים דברים
- **מחירים:** ב־`index.html`, בתוך `<form id="order">`, משנים את `data-price` של כל פריט. הסכומים והמחשבון מתעדכנים לבד.
- **טלפון:** מופיע ב־`index.html` (חפשו `053-6267521` ו־`972536267521`) ובשורה `PHONE` ב־`assets/js/main.js`.
  אחרי שינוי צריך ליצור מחדש את `assets/img/qr-whatsapp.svg`.
- **מבצע ההשקה:** מוחקים את הבלוק `<p class="launch">` מ־`index.html`.
- **סרטון אמיתי במקום תמונת ההמבורגר:** ב־`index.html`, בתוך `.phone__screen`, מחליפים את `<img …>` ב־
  `<video src="assets/video/sample.mp4" autoplay muted loop playsinline></video>`.
  אם הסרטון מדבר בעצמו, אפשר גם למחוק את `phone__hook`.
