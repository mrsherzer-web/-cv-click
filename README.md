# גל שמש — ביטים ושיעורי FL Studio

אתר תדמית וחנות ביטים: חנות עם נגן ורישיונות, עגלה שנשלחת לוואטסאפ, שיעורי FL Studio עם טופס הזמנה, ו-Channel Rack אינטראקטיבי בראש העמוד.

React + Vite + GSAP. בלי שרת ובלי מסד נתונים, אפשר להעלות לכל אחסון סטטי (Vercel, Netlify, GitHub Pages).

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לתיקיית dist
npm run preview  # תצוגה של הבנייה
```

## עריכת תוכן

כל הטקסטים, המחירים והביטים נמצאים בקובץ אחד: `src/data/site.ts`.

לפני העלייה לאוויר צריך לעדכן:

- **`contact`**: מספר וואטסאפ (בפורמט `9725XXXXXXXX`), קישורי אינסטגרם ויוטיוב, ומייל.
- **`licenses`** ו-**`licenseMatrix`**: מחירי הרישיונות ותנאי השימוש.
- **`lessonPlans`**: מחירים ותכולה של חבילות השיעורים.
- **`beats`**: רשימת הביטים (שם, ז'אנר, BPM, סולם, תגיות).

### הוספת ביט אמיתי

1. שמים את קובץ ה-MP3 (עם תג קולי) בתיקייה `public/beats/`, למשל `public/beats/red-line.mp3`.
2. ב-`src/data/site.ts` מוסיפים לביט את השדה `audio: "beats/red-line.mp3"`.

כל עוד אין לביט קובץ `audio`, האתר מנגן סקיצה שמסונתזת בדפדפן לפי השדה `pattern`. זה ממלא מקום עד שיעלו הביטים האמיתיים.

## איך עובדת ההזמנה

- **ביטים:** הלקוח בוחר רישיון ומוסיף לעגלה. בלחיצה על "שליחת ההזמנה" נפתח וואטסאפ עם רשימת הביטים, הרישיונות והסכום. התשלום (ביט, פייבוקס או אשראי) והעברת הקבצים נעשים ישירות מול גל.
- **שיעורים:** הטופס פותח וואטסאפ עם השם, המסלול, הרמה והפורמט.

אם בעתיד תרצו תשלום אוטומטי, אפשר לחבר את כפתור העגלה ל-Stripe, PayPal או ספק סליקה ישראלי.
