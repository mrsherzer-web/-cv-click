# הסנוקר של גפן 🎱👹

משחק אימה בדפדפן בסגנון "חמישה לילות": גפן התותח מזמין אתכם לשחק במשחק הסנוקר שלו... ואז שד משתלט עליו.
שרדו חמישה לילות, כל לילה מ־00:00 עד 06:00 (כל שעה במשחק = דקה וחצי).

## איך משחקים

1. **מסך פתיחה** – גפן מדבר אל המצלמה. כשהוא מסיים מופיע כפתור **התחל** בצד שמאל.
2. **הסרטון** – גפן נבלע בעולם של השד.
3. **"אין לכם לאן לברוח עכשיוווו"** – גפן המפחיד.
4. **חדר הסנוקר** – צמד הבקבוק האדום מזהיר אתכם... ואז גם הם נתפסים.
5. **בריחה** – לוחצים מהר על רווח / מקישים על המסך כדי לרוץ, ופונים שמאלה בזמן.
6. **הלילות** – יושבים בחדר הסנוקר הקטן עם המצלמות ושורדים עד 06:00.
   * לפני לילה 2 מגיעים **יהלי** (על הכיסא האדום) ו**מעיין** (עם הלייק) ומספרים מה קרה לגפן.
   * מלילה 2 גפן תוקף ברצינות, וצמד הבקבוק האדום מתחיל לתקוף מהדלתות.
   * בלילות 3–5 יש הודעות קשר מיהלי וממעיין.

### החוקים
| מי | מה הוא עושה | איך מתגוננים |
|---|---|---|
| **גפן** | עומד ליד השולחן במצלמה 1 ומתקרב כשלא מסתכלים עליו. כשהשולחן ריק – הוא רץ לדלת | להסתכל עליו במצלמה 1, ואם הוא נעלם – לסגור דלת (מלילה 3 – בדקו באיזה מסדרון הוא רץ) |
| **בעל הבקבוק** | מגיע מהצד **השמאלי** | להדליק אור שמאלי, ואם הוא שם – לסגור את הדלת השמאלית |
| **החייכן** | מגיע מהצד **הימני** | אותו דבר בצד ימין |
| **חשמל** | דלתות, אורות ומצלמות צורכים חשמל | אם החשמל נגמר... גפן מגיע עם קופסת נגינה |

### מקשים (מחשב)
`Q`/`E` דלתות · `A`/`D` אורות · `רווח` מצלמות · `1`–`9` החלפת מצלמה · `Esc` הפסקה · הזזת העכבר לצדדים = הסתכלות.
בטלפון: גוררים באצבע כדי להסתכל, והכפתורים על המסך. מומלץ לסובב את הטלפון לרוחב.

## הרצה

המשחק הוא אתר סטטי (HTML + JavaScript, בלי שלב בנייה). צריך להריץ אותו דרך שרת, לא בפתיחה ישירה של הקובץ:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר גם להעלות את התיקייה ל־GitHub Pages (Settings → Pages → לבחור את הענף) ולשחק מהטלפון.

## גרסה להורדה (קובץ אחד)

```bash
python3 tools/build_standalone.py
```

יוצר את `dist/gefen-snooker.html`: קובץ אחד שכל המשחק בתוכו. אפשר לשלוח אותו לחברים, והם פותחים אותו בלחיצה כפולה, בלי שרת ובלי אינטרנט.

## אפליקציה למחשב (Windows)

```bash
python3 tools/build_standalone.py
cp dist/gefen-snooker.html desktop/game/index.html
cd desktop && npm install && npm run build:win
```

נוצרת תיקייה `desktop/out/GefenSnooker-win32-x64` עם `GefenSnooker.exe`: חלון משלו עם אייקון, בלי דפדפן. אפשר גם `npm run build:mac` או `build:linux`.

## אפליקציה לטלפון (מסך הבית)

כשהמשחק עולה לאתר (למשל GitHub Pages), אפשר להתקין אותו כאפליקציה:
* **אייפון:** פותחים ב-Safari > שיתוף > "הוסף למסך הבית".
* **אנדרואיד:** פותחים ב-Chrome > תפריט > "התקן אפליקציה".

המשחק מקבל אייקון, נפתח במסך מלא, ועובד גם בלי אינטרנט (`sw.js` שומר את כל הקבצים). כשמשנים קבצים, מעלים את `VERSION` ב-`sw.js`.

## עריכה

| מה | איפה |
|---|---|
| כל הטקסטים והדיאלוגים | `src/story.js` |
| שמות הדמויות, קושי, אורך שעה, צריכת חשמל | `src/config.js` |
| מראה הממשק | `css/style.css` |
| החדרים במצלמות / החדר שלכם / המסדרון | `src/world/rooms.js`, `src/world/office.js`, `src/world/corridor.js` |
| הלוגיקה של הלילה והאויבים | `src/scenes/night.js` |
| כל הסאונד (מסונתז, בלי קבצים) | `src/engine/audio.js` |

**הקלטות קול אמיתיות:** כרגע הדמויות מדברות בקול המחשב העברי של המכשיר (אם יש), ותמיד יש כתוביות.
כדי להשתמש בהקלטה של החברים: שמים קובץ ב־`assets/voice/` ומוסיפים אותו ב־`VOICE_FILES` בתוך `src/story.js`, לפי ה־`id` של השורה, למשל:

```js
export const VOICE_FILES = { intro1: 'assets/voice/intro1.mp3', demon1: 'assets/voice/demon1.mp3' };
```

**בדיקות מהירות** (למפתחים): `?scene=night&night=3` קופץ ישר ללילה, `&speed=10` מריץ את הזמן מהר, `&dev` מציג את מצב האויבים, `&god` בלי מוות.

## התמונות

התמונות המקוריות נמצאות ב־`assets/source/`. הסקריפט `tools/prepare_assets.py` מייצר מהן את הדמויות החתוכות, את הגרסאות ה"דיבוקיות" עם העיניים הזוהרות, את פרצופי הקפיצה והפוסטרים (`assets/img/`).

קרדיטים טכניים: [three.js](https://threejs.org) (MIT), גופנים Heebo / Rubik Wet Paint / Rubik Glitch / Rubik Beastly / VT323 מ־Google Fonts (OFL).
