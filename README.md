# שעת הזהב

משחק דפדפן בתלת־ממד: קופצים עם רשת בין גורדי שחקים בעיר בזמן שקיעה. הגיבור הוא מי שתבחרו, עם הפנים שלו מתמונה, השם שלו על החזה, וכובע הגרב המפוספס.

המשחק רץ בדפדפן של הטלפון או המחשב, בלי התקנה.

## איך משחקים

| פעולה | טלפון | מקלדת |
| --- | --- | --- |
| קפיצה מגג / יריית רשת | לחיצה על כפתור **רשת** (או בכל הצד הימני של המסך) | רווח |
| התנדנדות | להחזיק את **רשת** | להחזיק רווח |
| עזיבה ועוף קדימה | לשחרר | לשחרר |
| כיוון | ג׳ויסטיק בצד שמאל | חצים או WASD |
| צלילה למטה | למשוך את הג׳ויסטיק אחורה | S או חץ למטה |
| זינוק | כפתור **זינוק** | Shift |
| החלפת מצלמה | כפתור המצלמה | C |
| הפסקה | כפתור ההפסקה | Esc |

שלוש מצלמות: **מאחור**, **עיני הגיבור** (מבט ראשון, כמו בסרטוני הסלואו־מושן) ו**סלפי** (רואים את הפנים של הגיבור).

**מרוץ הטבעות:** 12 טבעות זהב בין המגדלים. עמוד אור מסמן את הטבעת הבאה, והשעון מתחיל בטבעת הראשונה. השיא נשמר בדפדפן.

כשנתקלים בקיר של בניין, הגיבור מטפס עליו לבד עד הגג.

## התמונה של הגיבור

לוחצים על העיגול במסך הפתיחה, בוחרים תמונה, ומזיזים אותה כך שהפנים ימלאו את העיגול. התמונה מעובדת רק בתוך הדפדפן: היא לא נשלחת לשום שרת ולא נשמרת בקוד. היא נשמרת רק בטלפון שבו בחרתם אותה, כדי שלא תצטרכו לבחור אותה שוב.

## הרצה מקומית

המשחק טוען מודולים של JavaScript, ולכן צריך שרת מקומי קטן (פתיחה ישירה של הקובץ לא תעבוד):

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר גם להעלות את התיקייה ל־GitHub Pages: Settings ← Pages ← Deploy from a branch ← `main` / root.

## מבנה הקוד

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | המסכים, הכפתורים והעיצוב |
| `src/main.js` | לולאת המשחק, מסכים, אפקטים, רזולוציה מסתגלת |
| `src/city.js` | יצירת העיר (גורדי שחקים, נהר, גשר, פארק), שיידרים של חלונות, שמיים, מים וערפל |
| `src/player.js` | הפיזיקה: ריצה, קפיצה, נדנוד על חבל, טיפוס על קירות, זינוק |
| `src/hero.js` | הדמות, האנימציות, הפנים מהתמונה והכובע |
| `src/camera.js` | שלוש המצלמות והשוט של מסך הפתיחה |
| `src/rings.js` | מרוץ הטבעות |
| `src/traffic.js` | המכוניות ברחובות |
| `src/face.js` | חיתוך התמונה והפיכתה לפנים |
| `src/audio.js` | כל הצלילים, מסונתזים בקוד |
| `src/input.js` | מקלדת, עכבר ומגע |

הגרפיקה נבנית כולה בקוד עם [three.js](https://threejs.org) 0.160, שנטען מ־jsDelivr.
