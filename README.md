# SmartPantry · מה אוכלים בבית?

צילום אחד של המקרר → 3-4 מתכונים של 15 דקות, **רק ממה שיש בבית**. בלי להקליד מלאי, בלי לקפוץ לסופר, בלי וולט ב-80 ש״ח.

## מה יש באפליקציה
- **סריקה בשנייה** – צילום, כמה תמונות מהגלריה או וידאו של 3 שניות (נשלפים 3 פריימים).
- **זיהוי רכיבים ב-AI** (Claude Vision) – כולל קופסאות פתוחות, ירקות "עייפים" ושאריות, עם רמת ביטחון ועריכה ידנית.
- **מתכוני 15 דקות** – מנוע התאמה מקומי (24 מתכונים) + מתכונים חדשים שנוצרים ב-AI לפי מה שיש.
- **מצב "אפס מאמץ"** – רמת אנרגיה, 5/15 דקות, "בלי לשטוף מחבתות", סגנון מטבח.
- **חיסכון כספי** – מונה חיסכון חודשי מול מחיר משלוח שמגדירים בעצמכם.
- **מניעת בזבוז** – תוקף משוער לכל מצרך, והעדפה למתכונים שמצילים מצרכים שעומדים להתקלקל.
- **התאמה אישית ולמידה** – צמחוני/טבעוני/קטו/חלבון גבוה/ללא גלוטן, אלרגיות, ולמידה של הסגנונות שאתם מבשלים.
- **PWA** – אפשר להתקין על המסך הראשי. הממשק נטען גם בלי אינטרנט; הסריקה דורשת חיבור.

## עיצוב ותנועה
- **אייקונים במקום אימוג׳ים:** סט SVG אחיד בעובי קו אחד.
- **צבע:** ניטרלים עם נטייה ירוקה ומבטא אחד (אמרלד מעומעם), במצב בהיר ובמצב כהה.
- **טיפוגרפיה:** Rubik לכותרות, Heebo לטקסט, ספרות ברוחב קבוע בסכומים.
- **תנועה:** עקומות האטה מותאמות, תגובת לחיצה על כל כפתור, אנימציות קצרות מ-300ms, כניסה מדורגת לרשימות, מגירה בסגנון iOS שאפשר לגרור למטה כדי לסגור.
- **נגישות:** מצב "תנועה מופחתת" משאיר רק מעברי שקיפות.

## להשקה ולמכירה
**[מדריך ההשקה (docs/LAUNCH.md)](docs/LAUNCH.md)** – חשבון Claude API, העלאה ל-Vercel, אחסון, תשלומים, עלויות ורשימת בדיקות. כתוב למי שלא מתכנת.

## איך זה בנוי
```
דפדפן (index.html, js/)  →  שרת (api/, פונקציות Vercel)  →  Claude API
```
- **המפתח של Claude נמצא רק בשרת** (`ANTHROPIC_API_KEY`). למשתמשים לא צריך שום חשבון.
- **מכסות:** כל מכשיר מקבל מזהה אנונימי. בתוכנית החינמית יש מכסה חודשית, ויש גם מגבלה יומית לכל כתובת IP ותקרה יומית כוללת שמגינה על התקציב.
- **Premium בקודי הפעלה:** עובד עם כל ספק תשלום, כולל ספקים ישראליים. את הקודים יוצרים ב-`admin.html`.
- **הזיהוי אמיתי:** Claude עובר מדף אחרי מדף וקורא תוויות. המצרכים מגיעים לאפליקציה בזרם, אחד אחד, ברגע שהם מזוהים. בלי חיבור ל-AI הסריקה חסומה, ואף פעם לא מוצגת רשימה שלא זוהתה באמת.
- **תצוגה מקדימה ב-claude.ai:** כשאין שרת והאפליקציה רצה כארטיפקט, הזיהוי עובר דרך חשבון Claude של הצופה.

| נקודת קצה | תפקיד |
|---|---|
| `GET /api/config` | האם השרת מוכן, מכסות, מחיר וקישור רכישה |
| `GET /api/me` | התוכנית והמכסה של המכשיר |
| `POST /api/scan` | תמונות ← מצרכים בזרם NDJSON |
| `POST /api/recipes` | מצרכים והעדפות ← מתכונים (הפרומפט נבנה בשרת בלבד) |
| `POST /api/redeem` | הפעלת קוד Premium |
| `GET/POST /api/admin` | סטטיסטיקה ועלות, יצירה, בדיקה וביטול של קודים (מוגן ב-`ADMIN_TOKEN`) |

## הרצה מקומית
```bash
npm install
cp .env.example .env.local   # ממלאים ANTHROPIC_API_KEY ו-ADMIN_TOKEN
npm run dev                  # http://localhost:3000
npm test                     # בדיקות שרת מול Claude API מדומה
```

|---|---|
| `index.html` | מעטפת האפליקציה וניווט תחתון |
| `css/styles.css` | עיצוב (מובייל-first, RTL, מצב כהה) |
| `js/app.js` | מסכים: היכרות, בית, סריקה, מקרר, מתכונים, פרופיל |
| `js/engine.js` | התאמת מתכונים, תוקף, חיסכון |
| `js/ai.js` | חיבור לשרת (או ל-claude.ai), הכנת תמונות, זרם תוצאות |
| `js/prompts.js` | פרומפטים ופענוח תשובות – משותף לדפדפן ולשרת |
| `js/data.js` | קטלוג רכיבים ומאגר מתכונים |
| `js/icons.js` | סט אייקונים אחיד (SVG) |
| `js/store.js` | שמירת מצב מקומית |
| `assets/host*.jpg` | הדמות של האפליקציה |
| `api/` | פונקציות השרת; `api/_lib/` – Claude, מכסות וקודים, אחסון |
| `admin.html` | דף ניהול לבעלים |
| `privacy.html`, `terms.html` | טיוטות מדיניות פרטיות ותנאי שימוש (להשלמה ולבדיקה משפטית) |
| `scripts/dev-server.mjs` | שרת פיתוח מקומי |
| `tests/` | בדיקות שרת ו-Claude API מדומה |
