# מבצע ברודנה

משחק סיפור בתלת־ממד שרץ בדפדפן. ערב רגיל בקניון מיקס בחדרה נגמר בחטיפה. אתם משחקים בתור יונתי, והמטרה שלכם היא להציל את עידו הידנה (ברודנה).

## הפרקים

1. **קניון מיקס**: עידו ויונתי הולכים לסרט ופוגשים את יפתח. אחרי הסרט מגיעה שיחת וידאו מדולב, שמתנתקת באמצע משפט.
2. **הדרך לקציר**: נוהגים באוטו הלבן של יונתי בעליות של קציר.
3. **קציר**: פוגשים את יהלי בכיכר. יפתח לוקח אותו "לעזור במשהו", וכעבור שעה חוזר לבד.
4. **מצפה דור**: הוויכוח, הצעקה, ומשימת מעקב: עוקבים אחרי יפתח ועידו בלי שיראו אתכם. אחר כך החטיפה, שיחת טלפון לאברהם, ונסיעה לאסוף אותו.
5. **המפתחות**: מוצאים מפתח אדום באוטו של יפתח, פותחים את המחסן ליד מגדל המים, ולוקחים משם את המפתח הכחול של דלת הברזל.
6. **המחבוא**: יהלי ודולב קשורים בחדר אחד, ועידו בחדר השני, שמלא בלייזרים ולוחות לחץ. יפתח מסתובב בין שני החדרים עם פנס. משחררים את כולם, ואז בורחים כשהוא רודף אחריכם.
7. **זריחה**: הבוקר שאחרי.

המשימה הנוכחית תמיד מופיעה בצד ימין של המסך, עם רשימת שלבים וסימון של היעד. היא אף פעם לא באמצע המסך.

## איך משחקים

| פעולה | טלפון | מקלדת ועכבר |
| --- | --- | --- |
| הליכה | ג׳ויסטיק בצד שמאל | WASD או חצים |
| ריצה | לדחוף את הג׳ויסטיק עד הסוף | Shift |
| פעולה (לפתוח, לקחת, לשחרר) | הכפתור הצהוב | E או רווח |
| פעולה ארוכה (לשחרר חבר) | להחזיק את הכפתור הצהוב | להחזיק E |
| סיבוב מצלמה | גרירה בצד ימין של המסך | גרירת עכבר |
| המשך דיאלוג | נגיעה במסך | רווח, E או קליק |
| נהיגה | ג׳ויסטיק: למעלה גז, למטה ברקס, הצדדים הגה | W/S גז וברקס, A/D הגה |
| הפסקה | כפתור ההפסקה | Esc |

**התגנבות:** כשהקונוס של הפנס של יפתח נוגע בכם, המסך מתחיל להאדים. אם הוא נשאר עליכם, נתפסתם וחוזרים לנקודת הבדיקה האחרונה. ההתקדמות נשמרת: מי שכבר שוחרר נשאר משוחרר. ריצה ליד יפתח נשמעת, אז כדאי ללכת לאט כשהוא קרוב.

ההתקדמות בפרקים נשמרת בדפדפן, ואפשר לבחור כל פרק שכבר הגעתם אליו מהתפריט. בתפריט אפשר גם לכבות צליל, להפעיל הקראה בקול (אם יש בדפדפן קול בעברית) ולהוריד את רמת הגרפיקה בטלפונים חלשים.

## הפנים של החברים

הדמויות בנויות מהתמונות ומהסרטון ששלחתם. הפנים נסרקו מהתמונות (478 נקודות לכל פנים) והולבשו על ראש תלת־ממדי. תמונות הדיאלוג, כרטיסי הדמויות ושני הקטעים מהסרטון (שיחת הווידאו של דולב והפתיחה של יהלי) לקוחים מאותם קבצים.

כל המידע הזה יושב בתיקייה `private/`, ש**לא נכנסת ל־git** (היא מופיעה ב־`.gitignore`). ככה התמונות של החברים לא עולות למאגר. בלי התיקייה המשחק עדיין עובד, אבל לדמויות יש פנים מצוירות.

## הרצה מקומית

המשחק טוען מודולים של JavaScript, ולכן צריך שרת מקומי קטן:

```bash
cd brodna
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```
