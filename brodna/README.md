# מבצע ברודנה

משחק סיפור בתלת־ממד שרץ בדפדפן. ערב רגיל בקניון מיקס בחדרה נגמר בחטיפה. אתם משחקים בתור יונתי, והמטרה שלכם היא להציל את עידו הידנה (ברודנה).

## הפרקים

1. **קניון מיקס**: עידו ויונתי הולכים לסרט ופוגשים את יפתח. אחרי הסרט מגיעה שיחת וידאו מדולב, שמתנתקת באמצע משפט.
2. **הדרך לקציר**: נוהגים באוטו הלבן של יונתי בעליות של קציר.
3. **קציר**: פוגשים את יהלי בכיכר. יפתח לוקח אותו "לעזור במשהו", וכעבור שעה חוזר לבד.
4. **מצפה דור**: הוויכוח, הצעקה, ומשימת מעקב: עוקבים אחרי יפתח ועידו בלי שיראו אתכם. אחר כך החטיפה, שיחת טלפון לאברהם, ונסיעה לאסוף אותו.
5. **המפתחות**: מוצאים מפתח אדום באוטו של יפתח, פותחים את המחסן ליד מגדל המים, ולוקחים משם את המפתח הכחול של דלת הברזל.
6. **המחבוא**: יהלי ודולב קשורים בחדר אחד, ועידו בחדר השני, שמלא בלייזרים ולוחות לחץ. יפתח מסתובב בין שני החדרים עם פנס. משחררים את כולם, ואז בורחים כשהוא רודף אחריכם.
7. **זריחה**: הבוקר שאחרי.

המשימה הנוכחית תמיד מופיעה בצד ימין של המסך, עם רשימת שלבים וסימון של היעד. היא אף פעם לא באמצע המסך.

| הפסקה | כפתור ההפסקה | Esc |

**התגנבות:** כשהקונוס של הפנס של יפתח נוגע בכם, המסך מתחיל להאדים. אם הוא נשאר עליכם, נתפסתם וחוזרים לנקודת הבדיקה האחרונה. ההתקדמות נשמרת: מי שכבר שוחרר נשאר משוחרר. כשמתגנבים, יונתי מתכופף. ריצה מקימה אותו ונשמעת, אז כדאי ללכת לאט כשיפתח קרוב. במשימת המעקב סימון צהוב מראה איפה יפתח ומה המרחק אליו.

ההתקדמות בפרקים נשמרת בדפדפן, ואפשר לבחור כל פרק שכבר הגעתם אליו מהתפריט. בתפריט אפשר גם לכבות צליל, להפעיל הקראה בקול (אם יש בדפדפן קול בעברית) ולהוריד את רמת הגרפיקה בטלפונים חלשים.

## הפנים של החברים

הדמויות בנויות מהתמונות ומהסרטון ששלחתם. הפנים נסרקו מהתמונות (478 נקודות לכל פנים) והולבשו על ראש תלת־ממדי. תמונות הדיאלוג, כרטיסי הדמויות ושני הקטעים מהסרטון (שיחת הווידאו של דולב והפתיחה של יהלי) לקוחים מאותם קבצים.

כל המידע הזה יושב בתיקייה `private/`, ש**לא נכנסת ל־git** (היא מופיעה ב־`.gitignore`). ככה התמונות של החברים לא עולות למאגר. בלי התיקייה המשחק עדיין עובד, אבל לדמויות יש פנים מצוירות.

## גרסת המחשב (Windows)

יש שתי גרסאות מחשב, ושתיהן מריצות בדיוק את אותו משחק:

- **הגרסה הקלה** (התיקייה `pc/`, על Neutralino): קובץ התקנה של 2.3MB. המשחק רץ בתוך WebView2 של מיקרוסופט (המנוע של Edge), שכבר נמצא ב־Windows 10 ו־11. ההתקנה היא למשתמש הנוכחי ולא צריכה הרשאות מנהל. היא שמה קיצור דרך בשולחן העבודה ובתפריט התחל, ואפשר להסיר אותה כרגיל מ"אפליקציות מותקנות". אם WebView2 חסר במחשב, ההתקנה מציעה לפתוח את ההורדה הרשמית של מיקרוסופט.
- **הגרסה המלאה** (התיקייה `desktop/`, על Electron): מביאה דפדפן משלה, ולכן שוקלת בערך 110MB.

בשתי הגרסאות:

- הגרפיקה מתחילה ברמת **אולטרה**: החלקת קצוות אמיתית גם עם אפקטי האור, צללים חדים פי שניים, הצללה סביבתית (Ambient Occlusion) שמוסיפה עומק בפינות ומתחת לחפצים, וגרעין ושוליים כהים של סרט.
- **שלט** של Xbox או PlayStation: סטיק שמאלי הליכה, סטיק ימני מצלמה, A פעולה והמשך דיאלוג, Start הפסקה (ובתפריט: התחלה).
- **F11** או Alt+Enter למסך מלא, וכפתור יציאה בתפריט ובמסך ההפסקה.
- ההתקדמות וההגדרות נשמרות בין הפעלות, וגם אחרי הסרה והתקנה מחדש.

בגרסה הקלה המשחק גם מבקש את כרטיס המסך החזק, במחשבים ניידים שיש בהם שניים.

קבצי ההתקנה כוללים את הפנים של החברים (ראו למעלה), אז כדאי לשלוח אותם רק לחברים ולא להעלות אותם לאתרים ציבוריים.

### בנייה

המשחק נארז לקובץ HTML אחד בעזרת `tools/build-single.mjs`, שמכניס לתוכו את הקוד, את three.js, את הגופנים ואת התיקייה `private/` (אם היא קיימת). בגלל הפנים, הקובץ הזה לא נכנס ל־git.

```bash
cd brodna/tools
npm install
npm run build:neutralino    # pc/resources/index.html
npm run build:electron      # desktop/game/index.html

# הגרסה הקלה: קובץ המשחק, ואז קובץ ההתקנה (צריך NSIS 3)
cd ../pc
npx @neutralinojs/neu@11.7.2 update     # Neutralino 6.9.0 אל bin/
npx @neutralinojs/neu@11.7.2 build --release --embed-resources
cd installer
makensis installer.nsi                  # pc/dist/Mivtza-Brodna-Setup.exe

# הגרסה המלאה
cd ../../desktop
npm install
npm run dist:win                        # dist/Mivtza-Brodna-Setup-1.0.0.exe
```

## הרצה מקומית

המשחק טוען מודולים של JavaScript, ולכן צריך שרת מקומי קטן:

```bash
cd brodna
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

| `desktop/`, `pc/` | שתי גרסאות המחשב: Electron, ו־Neutralino עם קובץ ההתקנה (`pc/installer/`) |
